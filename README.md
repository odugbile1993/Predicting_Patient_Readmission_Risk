# AI Project: Predicting Patient Readmission Risk

## Project Overview
This project demonstrates the development of a machine learning system to predict the risk of patient readmission within 30 days of discharge. It covers the full AI lifecycle from problem definition and data preprocessing to model deployment and ethical considerations.

## Repository Structure
├── src/            # Source code for the project

│ ├── data_preprocessing.py

│ ├── model_training.py

│ └── inference_api.py

├── docs/                           # Documentation

│ └── ethical_analysis.md

├── notebooks/                    # Jupyter notebooks for exploration

│ └── data_analysis.ipynb

├── requirements.txt              # Python dependencies

└── README.md



## Key Features
- Data preprocessing pipeline for EHR data
- Model training with logistic regression and XGBoost
- API for model inference
- Fairness and bias evaluation tools

## Installation
1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Run the data analysis notebook for exploration
